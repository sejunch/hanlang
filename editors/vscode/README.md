# 한랭 VS Code 확장

교육용 한글 프로그래밍 언어 [한랭](https://github.com/sejunch/hanlang)(`.han`)을 위한 확장.

- **문법 색칠** — 키워드, 함수 정의, 묶음, 문자열, 숫자, 주석. 괄호·따옴표·숫자 뒤의 조사도 칠한다
- **오류 밑줄** — 저장할 때(와 열 때) `hanc` 로 검사해서 `[오류]`·`[경고]` 를 문제 패널과 밑줄로.
  hanc 가 가리킨 캐럿 자리에 정확히 긋고, 다형 함수 몸통의 오류는 "어디서 불렀나" 도 같이 보여준다
- **실행** — 편집기 오른쪽 위 ▶ 또는 `F5` (터미널에서 `han 파일.han`)
- **설명** — 키워드·내장 값(`말하다`, `빼다`, `제곱근`, `열쇠들` …)에 마우스를 올리면 쓰는 법
- **코드 조각** — `만약`, `동안`, `반복`, `목록돌기`, `함수`, `묶음`, `사전`, `파일읽기` … 치고 Tab
- `Ctrl+/` 주석, 괄호·따옴표 자동 닫기, 블록 접기

## 설치

한랭 저장소에서:

```bash
make vscode          # editors/vscode/hanlang-0.1.0.vsix 를 만들고 설치
```

설치 후 VS Code 창을 다시 불러오기(`Ctrl+Shift+P` → `Developer: Reload Window`).
지우려면 `code --uninstall-extension sejunch.hanlang`.

## 설정

| 설정 | 기본값 | |
|---|---|---|
| `hanlang.hancPath` | (비움) | 컴파일러 경로. 비우면 작업 폴더 → 파일 위 폴더들 → PATH 순으로 `hanc` 를 찾는다 |
| `hanlang.hanPath` | (비움) | 실행 스크립트 경로. 찾는 순서는 같음 (`han`) |
| `hanlang.checkOnSave` | `true` | 저장할 때 검사 |

## 왜 변수 뒤의 조사는 안 칠하나

한랭은 `나이를` 을 `나이` + `를` 로 가르는데, 이건 `나이` 라는 이름을 **아는지** 에 달려 있다
(`나` 만 알면 `나` + `이` 로 읽는다). 색칠만으로는 그걸 알 수 없어서, 틀리게 칠해 헷갈리게 하느니
안 칠하는 쪽을 골랐다. 진짜로 어떻게 갈랐는지는 저장했을 때의 `[경고]` 가 알려준다.
