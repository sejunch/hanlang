# 한랭 (hanlang)

한국어로 읽히는 교육용 프로그래밍 언어. C++로 짠 컴파일러가 x86-64 어셈블리를 뱉고 gcc로 링크한다.
인터프리터가 아니라 **진짜 네이티브 실행파일**이 나온다.

```
학생 이란 묶음 {
    이름은 문자.
    점수는 정수.
}

반은 []이다.
반에 (새 학생)을 넣다.
(반의 1번째)의 이름은 "세준"이다.
(반의 1번째)의 점수는 95이다.

만약 (((반의 1번째)의 점수) >= 90) 라면 {
    ((반의 1번째)의 이름)을 끝"(이)가 " 말하다.
    "1등!"이라고 말하다.
}
```

조사가 인자 이름표 노릇을 한다. `가와 나를 더하다` 로 정의하면 `3과 4를 더하다` 로 부른다.

## 빠른 시작

```bash
make                        # 컴파일러 빌드
./han examples/demo.han     # 한 번에 컴파일하고 실행
make test                   # 회귀 테스트 전부 돌리기
```

실행파일만 만들려면:

```bash
./hanc 프로그램.han -o 프로그램
./프로그램
```

## 설치

```bash
sudo make install           # 기본 /usr/local
han 프로그램.han
```

지울 때는 `sudo make uninstall`. 설치 위치는 `make install PREFIX=~/.local` 처럼 바꿀 수 있고,
라이브러리 폴더는 `HAN_LIB` 환경변수로도 지정할 수 있다.

## 뭐가 되나

- 타입: 정수 / 소수 / 문자 / 목록 / 격자(2차원) / 묶음(구조체)
  - 목록 안에 목록, 묶음 안에 묶음·목록, `없음` — 나무(트리) 같은 자료구조를 만들 수 있다
- 파일 읽기·쓰기: `파일 "a.txt"를 읽기로 열다 { 줄은 듣다. }` — 블록이 끝나면 저절로 닫힌다
- 쓰레기 수거(GC)가 있어서 오래 돌아도 메모리가 안 분다
- 함수: 타입을 안 적어도 되고, **인자 타입마다 알아서 따로 만들어진다**
  (같은 `정렬하다` 가 정수 목록에도 문자 목록에도 동작)
- 반복 제어 `멈추다` / `계속하다`, 몫 `~/`, 비트 연산 `& | ^ ~ << >>`
- 문자↔코드값 `("가"의 코드)` / `(65의 글자)` — 한글도 한 글자로 센다
- `"정렬.han"을 불러오다.` 로 라이브러리 가져오기 — 8개 파일 79개 함수가 있고,
  **전부 한랭으로 짜여 있어서 열어 읽을 수 있다**
- 범위 밖 접근, 0 나누기 등은 실행 중에 잡아서 한국어로 알려준다

**에러 메시지가 이 언어의 핵심 기능이다.** 한국어로, 소스 줄과 캐럿과 고치는 법까지 나온다:

```
[오류] 3행: '나이' 는 정수 변수인데 소수를 넣으려 함. 처음부터 소수로 쓰려면 0.0 처럼 만들기
  3 | 나이는 3.5이다.
    | ^^^^
```

## 문서

- [문법.md](문법.md) — 전체 문법 (이거 하나면 된다)
- [라이브러리.md](라이브러리.md) — 표준 라이브러리 79개 함수 전부 + 직접 만드는 법
- [examples/](examples/) — 데모 8개 (평균 계산기, 실전 입력, 구조체·비트·암호, 라이브러리 종합)
- [lib/](lib/) — 표준 라이브러리 8개. **전부 한랭으로 짜여 있으니 열어서 읽어봐도 된다**

| 라이브러리 | |
|---|---|
| `수학.han` | 최대공약수, 소수 판정, 팩토리얼, 자릿수 |
| `목록.han` | 정렬, 찾기, 복사, 이진탐색, 중복 제거 |
| `문자.han` | 자르기, 나누기, 대소문자, 다듬기 |
| `정렬.han` | 선택·삽입·퀵·병합 정렬 — **알고리즘 비교용** |
| `통계.han` | 평균, 중앙값, 최빈값, 분산, 표준편차 |
| `격자.han` | 격자 출력·복사·전치·이웃 세기 |
| `분수.han` | 유리수 사칙연산 — 소수와 달리 `1/10 + 2/10` 이 정확히 `3/10` |
| `큰수.han` | 자릿수 제한 없는 정수 — `100!` 도 158자리 그대로 |

컴파일러 내부는 `hanc.cpp` 주석에 단계별로 적혀 있다
(렉서 → 불러오기 → 조사 분리기 → 파서 → 타입 검사기 → 코드 생성).

## 파일

| | |
|---|---|
| `hanc.cpp` | 컴파일러 전체 (한 파일) |
| `han` | 컴파일하고 바로 실행하는 스크립트 |
| `lib/*.han` | 표준 라이브러리 8개 (전부 한랭으로 작성) |
| `tests/` | 회귀 테스트. `t_*` 는 통과가 정답, `e*` 는 컴파일 에러가 정답 |

## 아직 안 되는 것

이름공간, 사전(map). 변수는 단형이라 첫 대입에서 정해진 타입이 끝까지 간다 (함수만 다형).
